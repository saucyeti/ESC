# ESC
Can't be that hard right
BMS for a 10s2p pack, with cell monitoring, passive balancing, current measurements, and high side N-type Fets for protection. Communicates over CAN to the ESC, and provides +12V CAN power to the ESC for LV. Uses STM32F103 for main MCU and BQ76942 for cell monitoring

ESC for a 250W e-bike motor, with phase current measurements, running AM32 open-source firmware on STM32
